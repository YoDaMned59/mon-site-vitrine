# Site Vitrine - Développeur Freelance

Un site vitrine pour développeur freelance, construit avec React, Vite et SCSS.

## Lancer en local

```bash
npm install
npm run dev
```

Ouvrir l'URL affichée dans le terminal (souvent `http://localhost:5173`).

## Personnalisation

- Textes : `src/data/`
- Couleurs et polices : `src/styles/variables.scss`
- Pages légales : `/mentions-legales` et `/politique-confidentialite`

## Stack

React 19, Vite, React Router, SCSS, Lucide, EmailJS.
